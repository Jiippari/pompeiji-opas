# Pompeiji-opas

Suomenkielinen opas Pompeijin kaivausalueelle: kartta, kohteet, reitit ja ääneen luku.
Toimii Android-puhelimessa asennettavana verkkosovelluksena myös ilman nettiä.

Avaa opas: https://jiippari.github.io/pompeiji-opas/
